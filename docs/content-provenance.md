# 词库来源与编辑规则

## 来源

本项目全部释义、英文例句及中文翻译均在本次开发中由 AI 原创编写，并进行编辑检查。没有抓取或复制商业词典、付费词表、教辅书籍或真题原文。尚未经过外部英语教师独立审校。

词库归属是编辑选择，不代表官方考纲完整收录、官方推荐或统计得到的考试频次。页面因此始终标注「精选版，非完整考试词表」。不使用无依据的“必考”“高频排名”宣传。

## 覆盖范围

每个词库都由 100 个共同基础词和 50 个专项词组成，总计 300 个独立词条、600 个词库归属。

| 词库 | 专项内容 | 词数 |
| --- | --- | --- |
| 四级 | 校园、工作与日常生活 | 150 |
| 六级 | 抽象表达、论证与研究 | 150 |
| 雅思 | 住宿、城市、学习、就业与环境 | 150 |
| 托福 | 生命科学、地球科学、历史与认知 | 150 |

展示词性和释义对应例句中的一种常见用法，不声称涵盖所有词性和词义。单词使用小写英文词形作为稳定 ID，同一个词在任何专区只记录一份掌握进度。

## 检查

- 自动检查每库 150 个词、库内无重复、全局 ID 唯一、六个文本字段完整。
- 自动检查例句包含对应词形，避免词条例句错配。
- 编辑检查词性与所选释义匹配、主谓一致、搭配和译文对应，避免把拼写变化当作新词。
- 朗读使用设备的英语语音，不提供未经核验的音标。首页装饰词 grow 的音标为美式示意，不属于学习词条。

后续新增词条时，应同时新增原创释义/例句并通过相同检查。若引入外部数据，必须先记录真实来源 URL、许可证、取用范围和修改情况。
