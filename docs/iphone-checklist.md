# iPhone 真机验收

真实 iPhone 的安装、语音和飞行模式冷启动需在设备上完成；桌面移动视口测试不等同于真机通过。

- [ ] Safari 打开发布后的 HTTPS 网址，所有按钮与中文排版正常，无横向溢出。
- [ ] 分享 → 添加到主屏幕，图标显示书页和新芽，名称为「每日词记」。
- [ ] 主屏幕独立打开应用，底部导航不被 Home 指示条遮挡。
- [ ] 开始学习；揭晓前只显示英文，揭晓后显示释义与双语例句。
- [ ] 点击“忘了”，该词在队尾再次出现；当日已练数量不重复增加。
- [ ] 答完一词后关闭再打开，可继续下一词，累计已学数一致。
- [ ] 点击单词与例句朗读；设备无英语语音或离线不可用时有提示。
- [ ] 看到离线就绪提示后，开启飞行模式并彻底关闭再打开；词库、自测和保存可用。
- [ ] 导出备份；导入无效 JSON 时原进度不变；导入有效备份前有摘要和替换确认。
- [ ] 新版本发布后联网打开，按提示更新，已学数量和备份内容保持。
- [ ] 如从 Safari 切换主屏幕后进度不同，用导出/导入迁移并再次核对。
