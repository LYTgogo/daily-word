# 每日词记 1.1

- 在四级、六级、雅思或托福词库点击「添加单词」。英文和中文释义必填，词性、例句、翻译可选；新增词参与每日学习与间隔复习，新词中优先安排个人添加的词。
- 相同英文词条忽略大小写和首尾空格合并，跨词库共享进度与备注，保留已有词条的释义。
- 点击词条，在「我的备注」填写学习来源或记忆技巧并保存；揭晓学习卡片时也显示备注。
- 「我的」新增每日新词进度条，按 5 / 10 / 15 / 20 词目标计算，每个新词只计数一次；复习不占用新词目标。
- 词库默认折叠，可展开全部单词，列表底部也可折叠；搜索直接显示匹配词条。
- 两个首页词库卡片均采用黑色悬停边框，修复雅思托福样式覆盖问题。
- 本机数据和导出备份升级为 version 2，包含 customWords 与 notes；旧版 version 1 数据和备份自动兼容，保留原有学习记录。无效备份不替换数据。

验证：13 项 Node 测试、8 项 Chromium 浏览器测试和 TypeScript/Vite 生产构建通过。覆盖新增词、重复词合并、跨词库共享、备注、备份兼容与往返、离线重开、目标进度、折叠与搜索、悬停边框。手机视口检查不代替真实 iPhone 测试。
